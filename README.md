# Lunar Store — минимальная версия (бета)

Маркетплейс игровых товаров и услуг. Android (Java) + Spring Boot (Java) + PostgreSQL.
Реальных платежей нет — пополнение/вывод работают как заглушки.

## Запуск
1. **База**: PostgreSQL, база `lunarforge_market`, логин/пароль `postgres`/`postgres`
   (или `cd backend && docker compose up -d`).
2. **Сервер** (нужна **Java 25**): открыть `backend` в IntelliJ IDEA как Maven-проект.
   File → Project Structure → SDK → Download JDK → 25 (Eclipse Temurin). Запустить `MarketApplication`, порт 8080.
   Spring Boot 3.5.16. Обработка аннотаций Lombok включена в `pom.xml` (`<proc>full</proc>`) - на JDK 23+
   без этого Lombok молча не работает.
3. **Сеть**: телефон и ПК в одной Wi-Fi сети. Адрес сервера - `ApiClient.BASE_URL`
   (сейчас `http://192.168.50.32:8080/`). Один раз открыть порт (PowerShell **от администратора**):
   `New-NetFirewallRule -DisplayName "LunarForge 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow`
   Проверка с телефона в браузере: `http://192.168.50.32:8080/api/games`. Если не открывается -
   выключите VPN на телефоне. Если роутер сменил IP компьютера (`ipconfig`) - поменяйте адрес в `ApiClient.java`
   или закрепите IP за ПК в настройках роутера.
4. **Приложение**: открыть `android` в Android Studio → Gradle Sync → Run.
   Gradle 9.5.1, AGP 9.3.0, compileSdk 37, **targetSdk 36** - намеренно: в Android 17 при targetSdk 37
   нужно отдельное разрешение на локальную сеть, иначе приложение не увидит сервер на компьютере.
   Библиотеки - последние стабильные: AppCompat 1.8.0, Material 1.14.0, CameraX 1.6.2, Retrofit 3.0.0,
   OkHttp 5.5.0, Glide 5.0.9.

Тестовые аккаунты создаются сами при первом запуске сервера:
**админ: почта `lunixmode.dev@gmail.com`, пароль `admin`** (ник Lunix, @lunix, в профиле значок «👑 Создатель»). В меню ☰ появится «Доход площадки». Пароль задаётся в `DataSeeder.java` - перед реальным запуском поменяйте на надёжный.

**Тестовые аккаунты** (создаются сами при старте, если их нет): `test1@gmail.com`, `test2@gmail.com`,
`test3@gmail.com`, пароль `123456` (ник и @username - test1/test2/test3). Удобно проверять споры: test1 покупает
у test2, а создатель разбирает заявку (свою собственную заявку разбирать нельзя - даже создателю).
**Перед настоящим запуском** выключить: `lunar.seed-test-users=false` в `application.properties`.

## Что есть
- **Регистрация/вход**: email, никнейм (можно менять в профиле тапом по нему, может повторяться) и уникальный @username (не меняется, не только из цифр).
- **Игры и приложения** с подкатегориями (Roblox → Robux, Roblox Plus, Плейсы; PUBG → UC, Донат, Аккаунты) + папка «Другое».
- **Поиск**: на главной — поиск игр; внутри игры — поиск товара + фильтры (подкатегория, тип, сортировка по цене/новизне).
- **Выставление товаров/услуг**: игра, подкатегория, тип (предмет/услуга/донат), количество или «бесконечно»,
  главное фото + до 5 дополнительных (листаются в карточке товара, тап - на весь экран).
  Продавец может скрыть товар с витрины и вернуть обратно.
  Продавец сразу видит цену для покупателя.
- **Фиксированная комиссия 5%** (`ListingService.COMMISSION_RATE`) — покупатель везде видит и платит цену с комиссией.
- **Покупка (эскроу)**: выбор количества → оплата → деньги заморожены → приложение открывает чат с продавцом,
  Lunar Bot пишет «Куплен заказ #N … × количество … ожидает выполнения». Покупатель подтверждает получение →
  деньги уходят продавцу, но **48 часов заморожены** (`OrderService.WITHDRAWAL_HOLD_HOURS`), у каждого заказа свой таймер.
  **Отменить заказ может только продавец** (деньги возвращаются покупателю, товар - в наличие).
  Покупатель отменить не может: иначе можно получить товар, отменить и вернуть деньги. Если товар
  не получен - покупатель просто не подтверждает заказ и пишет продавцу.
- **Чат как в Telegram**: текст, фото, видео (скрепка), голосовые и **кружочки**.
  Кнопка справа: короткий тап - переключить 🎤/📹, **удерживать - запись, отпустить - отправить**,
  смахнуть **вверх к 🔒** - запись без рук (потом «отправить»/«удалить»), смахнуть **влево** - отмена.
  Кружки (до 60 сек) пишутся прямо в приложении с фронтальной камеры и проигрываются прямо в круге.
  Сообщения нельзя редактировать и удалять. Сообщения Lunar Bot - системные плашки по центру.
- **Кошелёк**: доступно / заморожено, пополнение и вывод (заглушки с номером карты), история операций,
  **переводы другому пользователю по ID или @username без комиссии**.
- **Аналитика** в профиле: кружки «потрачено / заработано / сделок».
- **Отзывы**: только после завершённого заказа, 1–5 звёзд + текст, можно менять раз в 24 ч,
  автор скрыт от всех кроме самого продавца, сумма покупки округлена до 10. Средний рейтинг в профиле.
- **Аватар**: в профиле нажмите на аватар и выберите фото из галереи.
- **Чат → профиль**: нажатие на имя в шапке чата открывает профиль собеседника.
- **Профиль продавца**: ник, @username, ID, рейтинг, дата регистрации, сворачиваемые списки товаров и отзывов.
- **Админ**: пункт «Доход площадки» в меню (виден только админу) — сумма комиссии всего и по месяцам.
- **Светлая и тёмная тема**: по умолчанию как в телефоне; в меню ☰ → «Тема оформления» можно выбрать
  «Как в системе / Светлая / Тёмная» и цвет акцента. Все цвета - в `res/values/colors.xml` (светлая)
  и `res/values-night/colors.xml` (тёмная); контраст текста проверен по WCAG.

## Поддержка и модерация
- **Заявки пользователя** (☰ → «Поддержка»): проблема с заказом (сервер сам определяет, покупатель вы или продавец),
  проблема с аккаунтом, возврат в модераторы (только бывшим модераторам). В заказе - «Запросить возврат»
  (заказ замораживается до решения) и «Проблема с заказом». В профиле человека - «Пожаловаться».
- **Модератор** берёт заявку, читает переписку сторон и пишет прямо в их чат - сообщения подписаны
  🛡️ Модератор ник / 👑 Админ ник. Один ответственный на заявку; если люди ответили, а он молчит 8 часов -
  заявку может перехватить другой (админ - в любой момент). Фильтры: новые / мои / в работе / решённые / все,
  по типу заявки и по тому, кто подал.
- **Решения**: возврат - полный / частичный (при вводе суммы сразу видно: сколько покупателю, сколько продавцу
  и какая комиссия) / в пользу продавца; жалоба - закрыть / заблокировать;
  разблокировка - разблокировать / оставить; обжалование - решение верное / ошибочное (+ компенсация от площадки).
- **Обжалование**: в течение 7 дней, один раз, рассматривает другой модератор. Если решение ошибочное -
  площадка может выплатить компенсацию (у продавца ничего не забирается).
- **Блокировки**: модераторы и админ, из профиля человека или по жалобе. Модератора напрямую блокирует
  только админ, остальные - только через жалобу на него. Заблокированный видит только экран блокировки,
  подаёт апелляцию и пишет в чат поддержки. Апелляцию не может разбирать тот, кто блокировал.
- **Рейтинг модератора 0-100**: снижают 👎 участников, отменённые решения и блокировки, снятые по апелляции.
  Оценивают только заявитель и стороны заказа (не нарушитель). Ниже 40 при 10+ решённых заявках -
  **снимается автоматически**.
- **Админ** (☰ → «Модераторы»): «Команда» с рейтингом и «Снятые» (за рейтинг, за блокировку, вручную) -
  вернуть на должность, разблокировать, подробная статистика: все заявки и все блокировки модератора.

## Уведомления, операции, аватарки
- **Колокольчик** со счётчиком: новые заказы, деньги, разморозка, переводы, отзывы, заявки, блокировки.
  Тап ведёт прямо в заказ / заявку / операцию. Системные уведомления Android - пока приложение запущено
  (для уведомлений при закрытом приложении нужен Firebase Cloud Messaging).
- **Подробности операции**: сумма, с кем (аватар, ник), сообщение к переводу отдельной карточкой, заказ,
  когда разморозятся деньги.
- **Темы**: светлая / тёмная / как в системе (по умолчанию) и цвет акцента: синий, фиолетовый, зелёный, розовый,
  бирюзовый, оранжевый или **«Авто по временам года»** - зимой синий, весной зелёный, летом бирюзовый, осенью оранжевый.
- **Аватарки**: своё фото с обрезкой по кругу. Без фото - круг с первой буквой ника в цветах текущего месяца.
  Каждый сезон - в гамме цвета темы «Авто по временам года» (зима синие, весна зелёные, лето бирюзовые,
  осень оранжевые), при этом три месяца внутри сезона разные. Контраст буквы проверен.

## Код
Важные места в коде прокомментированы на русском (деньги, блокировки, чат и запись, безопасность).

## Надёжность
- **Жизненный цикл**: всё, что экран запускает (опрос чата и колокольчика, таймеры, камера, диктофон, плееры),
  останавливается в `onPause`/`onDestroy`. Ответ сервера, пришедший после закрытия экрана, игнорируется -
  без падений и лишней работы. Статических ссылок на экраны нет (утечек памяти нет); картинки кэширует Glide,
  он сам освобождает память, когда системе её не хватает.
- Все операции с деньгами (покупка, подтверждение, отмена, перевод, пополнение, вывод, разморозка)
  блокируют строки в БД на время операции - двойное нажатие или два устройства не приведут
  к двойному списанию или двойной выплате.
- Суммы: больше 0, не больше 2 знаков после запятой, не больше 1 000 000 ₽ за операцию.
- Загружаются только фото/видео/аудио до 25 МБ. Ошибки сервера приходят понятным текстом,
  приложение показывает их как есть («Недостаточно средств: нужно 550 ₽, доступно 120 ₽»).
- Истёк токен (7 дней) - приложение само возвращает на экран входа.

## Чего пока нет
- **Настоящих платежей** - пополнение и вывод пока заглушки. В планах: оплата картами и подтверждение почты
  при регистрации (последним этапом, вместе с выкладкой сервера в интернет).
- Уведомлений при полностью закрытом приложении (нужен Firebase Cloud Messaging).
- Звонков - нужна отдельная инфраструктура (WebRTC/TURN или готовый SDK).
